# Contributing to Náu POS

Thanks for your interest in contributing!

1. Open an Issue describing the bug or proposal.
2. Create a branch from `main` (e.g. `fix/receipt-print`).
3. Keep changes focused and avoid altering unrelated code.
4. Test changes with **dummy data**, never live customer or sales records.
5. Open a pull request explaining the change, test results, and possible risks.
6. Wait for review before merging.

Please do not post credentials, real customer data, payment details, or sensitive logs in issues or pull requests.

**Critical paths:** Payments, inventory deduction, authentication, database persistence, and recovery require particular care. Do not assume a passing syntax check is sufficient.
